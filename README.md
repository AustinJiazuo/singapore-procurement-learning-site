# 新加坡采购学堂（Singapore Procurement Academy）

一个面向中文学习者的新加坡采购行业学习网站。纯静态实现（HTML/CSS/原生 JS），无任何外部依赖与构建步骤，直接用浏览器打开 `index.html` 即可使用，也可部署到 GitHub Pages 等任意静态托管。

## 内容结构

| 页面 | 内容 |
| --- | --- |
| `index.html` | 首页：模块导航、推荐学习路径、学习进度 |
| `overview.html` | 模块 1 · 新加坡采购行业概览 |
| `government.html` | 模块 2 · 政府采购与 GeBIZ（采购方式与金额门槛、评标、供应商注册） |
| `process.html` | 模块 3 · 采购全流程实务（S2C/P2P、RFx、TCO、谈判、合同） |
| `legal.html` | 模块 4 · 法律法规与合规（合同法、PDPA、反腐败、竞争法、进出口） |
| `supplychain.html` | 模块 5 · 供应链与物流生态（港口枢纽、FTZ、Incoterms、韧性） |
| `career.html` | 模块 6 · 职业发展与认证（职业阶梯、SIPMM/CIPS/CPSM、SkillsFuture） |
| `glossary.html` | 模块 7 · 中英对照采购术语表 |
| `quiz.html` | 自测题库：按章节筛选、即时判分、附解析 |

## 功能

- 响应式布局，自动适配深色模式，支持打印
- 「标记为已学」学习进度（仅保存在浏览器 localStorage，本地私有）
- 按章节筛选的单选自测题库，即时判分并给出解析

## 免责声明

内容仅供学习参考，不构成法律或职业建议。涉及金额门槛、税率与法规的内容，请以新加坡财政部（MOF）、GeBIZ、新加坡海关等官方渠道的最新发布为准。
